# Обязательные правила для агента (Project Rules)

Следующие правила должны строго соблюдаться агентом при работе над данным проектом:

1. **Правило «Хирургического вмешательства»:**
   - Никогда не переписывай весь файл целиком, если он больше 100 строк.
   - Используй только точечные правки: заменяй только конкретный кусок функции/кода, сохраняя все остальные пропсы, логику и сокеты нетронутыми.

2. **Обязательная проверка `git diff` перед коммитом:**
   - Перед тем как делать коммит, обязательно открой терминал и выполни команду `git diff`.
   - Внимательно проверь изменения (удаленное и добавленное). Убедись, что не удалена жизненно важная логика (например, куски логики сокетов или критические вызовы функций), чтобы избежать багов до начала сборки.

3. **Архитектурные файлы неприкосновенны:**
   - Такие файлы, как соединения сокетов (например, `socket.ts`), логика WebRTC-звонков и контекст авторизации, закрыты для случайных или глубоких правок.
   - Любые новые фичи должны подключаться к этим файлам снаружи (через экспортируемые методы/интерфейсы), а не вмешиваться во внутреннюю реализацию их логики.
