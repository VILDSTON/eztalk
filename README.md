# 💬 EzTalk — Minimalist Real-Time Messenger

> **Clean, noise-free communication for friends.** Built for speed, privacy, and simplicity.

---

## ⚡ Overview

**EzTalk** is a lightweight web messenger designed with a sleek **Discord Dark & Neon Green** aesthetic. Unlike feature-bloated platforms overloaded with servers, infinite channels, and bots, EzTalk strips away the noise to focus on what matters most: **direct 1-on-1 conversations and close circles**.

Designed and prototyped in record time using **Gemini 3.7 Flash** (Extended Thinking).

---

## ✨ Key Features

- 💬 **Real-Time Direct Messaging:** Instant, bi-directional message delivery with zero page reload.
- 👥 **Clean Friends List:** Easily search by `@username`, manage friend requests, and see live online/offline statuses.
- ⚡ **Lightweight & Fast:** Zero bloat, instant load times, minimal RAM footprint compared to desktop clients.
- 🛡️ **Noise-Free Environment:** No complicated server roles, public channels, or notification spam.
